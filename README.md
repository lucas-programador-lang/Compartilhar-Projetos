# Compartilhar Projetos

A vitrine para suas ideias. Publique seus projetos, receba feedback da comunidade e ganhe visibilidade.

🔗 [compartilhar-projetos.com.br](https://compartilhar-projetos.com.br)

## O que é

Compartilhar Projetos é uma plataforma por assinatura onde desenvolvedores e criadores publicam seus projetos, recebem feedback da comunidade e ganham visibilidade. Conta com:

- **Explorar projetos** — vitrine pública de projetos publicados pela comunidade
- **Comunidade** — espaço para interação entre os usuários
- **Planos de assinatura** — acesso pago para publicar projetos
- **Ranking** — destaque mensal para os usuários mais engajados
- **Programa de indicações** — comissão por indicações que assinam
- **Painel administrativo** — moderação de projetos, usuários e saques
