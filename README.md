# CompartilharProjetos — Android

Projeto Android Studio que transforma https://compartilhar-projetos.com.br/ em um aplicativo Android usando WebView.

## Abrir
1. Instale o Android Studio.
2. Abra esta pasta como projeto.
3. Aguarde a sincronização do Gradle.
4. Conecte um aparelho Android ou crie um emulador.
5. Execute `app`.

## Gerar APK
Android Studio: Build > Build APK(s).

## Observação
O aplicativo usa o site como backend/interface, portanto login, cadastro, projetos, comunidade, planos, ranking, indicações e demais áreas continuam sincronizados com a plataforma web.
